# FixPilot — Free Online AI Tools

Your pilot to fix any file. 20+ free online tools powered by AI.

## Live at: fixpilot.vercel.app

## Tools
- Compress PDF
- Merge PDF
- Split PDF  
- Image Compressor
- QR Code Generator
- Image to Text (OCR)
- PDF to Word
- More coming soon...

## Tech Stack
- Pure HTML/CSS/JS (no frameworks)
- Client-side processing (pdf-lib.js, Tesseract.js)
- Hosted on Vercel (free)
- AI APIs: Groq, Gemini (free tiers)
